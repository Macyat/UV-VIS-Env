# 术语表（Glossary）

一个术语对应一个解释。取值 / 代码位置写在解释里。按主题分类整理：

## 一、水质参数与国标分类

| 术语 | 解释 |
|---|---|
| **水质参数** | 被监测的水质指标：CODMn（高锰酸盐指数）、COD（化学需氧量）、TN（总氮）、TP（总磷）、AN（氨氮）、TUR（浊度）。 |
| **类别（Ⅰ~Ⅴ类）** | GB 3838 的地表水水质类别，Ⅰ类最好、Ⅴ类最差；`params.yaml` 的 `ranges` 即各类分界值。 |
| **劣Ⅴ类** | 读数 ≥ Ⅴ类限值，比最差类别还差，触发超标。 |
| **标准限值 `ranges`** | 各参数 I~V 类分界浓度，取自 GB 3838 表 1，是所有阈值的基准。 |
| **GB 3838-2002** | 《地表水环境质量标准》，阈值来源。 |
| **HJ 915.3-2024** | 《地表水水质自动监测站运行维护技术规范》，量程/报警设定与异常情况处置的程序依据。 |
| **超标报警** | 读数 ≥ V 类限值（`ranges[-1]`）即判"劣Ⅴ类"超标，属水质分类报警；见 `alarm_accuracy`。 |
| **金标准（gold standard）** | 实验室化学法测定的浓度，作为样本物质浓度标签（参考真值）的权威基准。 |
| **标准分析方法 `standard`** | 各参数对应的化学法：CODMn→GB 11892-89、COD→HJ 828-2017、TN→HJ 636-2012、TP→GB 11893-89、AN→HJ 535-2009、TUR→HJ 1075-2019。 |
| **异常情况处置** | HJ 915.3-2024 规定的现场运维动作，读数异常时的程序入口。 |

## 二、边界与三道处理（检出限 / 复核限 / 理论上限）

| 术语 | 解释 |
|---|---|
| **检出限 `lower_bound`** | 国标实验室方法的检出限；预测值低于它替为 LOD/2 并标记 `below_lod`。 |
| **光谱模型自身检出限** | 由 `figures_of_merit` 从数据算出，通常远大于国标方法检出限，不能拿国标值代替。 |
| **复核限 `review_upper`** | = 1.5 × V 类；超过仍显示，标记 `above_review`（需复核）。 |
| **理论上限 `theoretical_upper`** | = `min(设备理论上限, 河流理论上限)`；物理上不可能，不显示（置 NaN），标记 `not_display`。 |
| **设备理论上限 `device_theoretical_upper`** | 默认 2 × 最高校准标样（训练时算），可手填覆盖；传感器饱和 / 超出方法量程，设备测不出。 |
| **河流理论上限 `river_theoretical_upper`** | 默认 2 × V 类，可手填覆盖；这条河物理上不可能有的浓度。 |
| **三区处理** | `apply_bounds` 的规则：低于 LOD→LOD/2；复核区保留原值；超理论上限→NaN。 |
| **量程/报警上限（HJ 915.3）** | 仪器量程上限/质控报警，取 2 × 标准限值，对应本系统理论上限；与"超标报警（V 类）"是两回事。 |
| **复核（复验）** | 光谱读数超过复核限后，安排实验室化学法做一次确认。 |
| **校准标样** | 训练校正集里的参考浓度；其最大值用于自动算设备理论上限（×2）。 |

## 三、分析方法品质因数（FOM）

| 术语 | 解释 |
|---|---|
| **指标（FOM）** | `figures_of_merit` 一次性输出的 `{SEN, gamma, s_x, s_0, LOD, LOQ, SEL}`。 |
| **回归向量 `b`** | 模型在浓度方向上的系数向量（线性取 `coef_`，非线性数值微分）。 |
| **灵敏度 `SEN`** | `1 / ‖b‖`，越大越灵敏。 |
| **分析灵敏度 `γ`** | `SEN / s_x`，单位浓度的信噪比。 |
| **空白（方法空白/试剂空白）** | 与样品基质一致、不含被测物的溶剂，UV 水质场景即纯净水/去离子水。用于估计 `s_x`、`s_0`。严格按此定义；地表水取不到绝对零浓度时可用"近检出限低浓度水样"近似，但优先纯水/去离子水。测 `s_x`/`s_0` 需同条件独立重复 ≥10 组（最少 ≥2，否则 s_0 退化）。 |
| **光谱噪声 `s_x`** | 空白样本（与样品背景一致、不含被测物的溶剂，即纯净水/去离子水）去趋势后的残差标准差。需 ≥10 组独立重复空白估计。 |
| **空白预测标准差 `s_0`** | 空白样本（与样品背景一致、不含被测物的溶剂，即纯净水/去离子水）预测值的标准差，即多次重复测纯水的预测散布；用于算 LOD/LOQ。空白必须保留原始噪声、且未被替为 LOD/2，否则会塌成常数导致 s_0=0；`n_blank=1` 时 s_0 静默退化为 0，需 ≥2 组。 |
| **检出限 `LOD`（多元）** | `3.3 · s_0 / SEN`；不能用单变量 3σ/slope 口径。 |
| **定量限 `LOQ`** | `10 · s_0 / SEN`。 |
| **选择性 `SEL`** | 目标组分净信号占总信号的占比（0~1）。 |

## 四、建模与数据契约

| 术语 | 解释 |
|---|---|
| **光谱软测量** | 用紫外-可见光谱 + 回归模型估计水质浓度，替代/辅助化学法。 |
| **多元校正** | 把整条光谱（多变量）映射到浓度，而非单波长 Lambert-Beer。 |
| **预处理链 `preproc_chain`** | YAML 可复现的预处理步骤（savgol / snv / msc / mean_center 等）。 |
| **指纹 `fingerprint`** | 预处理链 + 波长轴 + 模型名的哈希，部署端校验一致性。 |
| **波长轴 `wavelengths`** | 部署端必须逐点匹配的波长网格。 |
| **ModelCard** | 训练产物 = 估计器 + 预处理链 + 指纹 + 指标 + 仪器 ID。 |
| **估计器 `estimator`** | 被 `WaterQualityModel` 包装的回归器（PLS/Ridge/Lasso/…）。 |
| **x/y 缩放** | `x_mean_` / `y_mean_` / `y_scale_`，训练与推理同源的中心化/标准化。 |
| **数据版本 `data_version`** | 训练数据哈希，写进 ModelCard 溯源。 |

## 五、过程监控（MSPC 与控制图）

| 术语 | 解释 |
|---|---|
| **MSPC** | Multivariate Statistical Process Control（多变量统计过程控制），把整条光谱压成 T² / SPE 两个统计量。 |
| **T²（Hotelling）** | 模型内部正常波动方向上的偏离。 |
| **SPE（Q 残差）** | 模型解释不了的变异，探头污染/气泡/异物最常体现在这。 |
| **贡献图 `contribution`** | 把 SPE 拆回各波长，定位"哪个波长段出问题"。 |
| **控制图** | Shewhart / CUSUM / EWMA，`control_charts`。 |
| **ARL** | 平均运行长度，评价控制图灵敏度（3σ 下 ≈ 370）。 |

## 六、部署与迁移

| 术语 | 解释 |
|---|---|
| **edge runtime** | 工控机部署运行时，依赖与 aimeta 一致（numpy / scipy / PyWavelets）；纯 numpy 链可零额外依赖运行。 |
| **train/serve 一致性** | 训练端与 edge 端预测逐元素一致（`verify_against_card`）。 |
| **仪器迁移 `transfer`** | DS / PDS / SBC / GLSW 等，让模型跨仪器可用。 |

## 七、验收指标

| 术语 | 解释 |
|---|---|
| **报警准确率 `alarm_accuracy`** | 预测值是否触发"超标报警"判定与国标真值一致的命中率（含漏报/误报），验收指标之一；代码 `aimeta/metrics/water_standards.py`。打分表列记为 `alarm_acc`。 |
| **报警误差 `alarm_err`** | 报警判定的错误率 = 1 − `alarm_accuracy`；打分表列记为 `alarm_err`。 |
| **日级 R² `daily_r2`** | 按采样日（`day_idx`）分组，逐日计算预测 vs 真值的 R²（及 Pearson r），衡量模型在"同一天"样本上的稳定性；`aimeta/metrics/water_standards.py:daily_r2`。打分表列 `daily_r2_score` / `daily_pearson_r_score`。 |
| **达标率 `acceptance_rate`** | 预测值与国标真值落在允许误差带（绝对误差 `abs_error_bound` 与相对 `mape_bound`）内的样本占比，验收合格比例；代码 `aimeta/metrics/water_standards.py:acceptance_rate`。打分表列 `rate of reaching the standard`。 |

## 八、光谱仪硬件评价

| 术语 | 解释 |
|---|---|
| **光谱仪硬件评价** | 评价**仪器自身**状态与跨机一致性（区别于「三、FOM」评价的是分析方法/模型）。函数集中在 `aimeta/hardware_eval.py`，依据 JJG 178 / ASTM E275；`evaluate_instrument` 一次性汇总（有数据才算、缺项跳过）。 |
| **波长准确度** | 实测峰位 vs 标称峰位（钬玻璃/汞灯标准峰）的最大绝对误差（nm），峰位在参考峰 ±window 内抛物线细化；`wavelength_accuracy` / `find_peak_wavelength`。典型合格 ≤ 0.5 nm。 |
| **光度准确度** | 实测吸光度 vs 认证值（中性密度片/重铬酸钾）在认证波长点插值的最大绝对误差；`photometric_accuracy`。典型合格 ≤ 0.002 A（或 0.3 %T）。 |
| **杂散光** | 截止滤光片完全截止波长处实测到的残余透射（%T）；`stray_light`。典型合格 ≤ 0.05 %T。 |
| **暗噪声** | 遮光（shutter 关闭/暗室）下 ≥2 次重复暗谱的逐波长标准差（ddof=1），报告 `std_max`/`std_mean`；`dark_noise`。 |
| **基线平直度** | 100%T 参考线多次重复的逐波长跨重复 std（`repeatability_max`），及平均基线相对 ideal 的最大偏离（`deviation_max`）；`baseline_flatness`。 |
| **信噪比 `SNR`** | 信号均值 / 重复标准差（ddof=1），在指定波长或全波段均值上算，噪声为 0 返回 `inf`；`signal_to_noise`。 |
| **分辨率 `FWHM`** | 窄发射线（汞灯/氩灯）的半高全宽（nm），抛物线细化峰高后线性插值求 FWHM；`resolution`。典型合格 FWHM ≤ 2 nm。 |
| **标液线性度（各波长）** | 多浓度梯度标液，逐波长按浓度逐步累加做线性回归（吸光度→浓度）的累计 R²，判定各波长线性范围；`standard_solution_linearity`（绘图 `plot_linearity_r2`）。R² 越接近 1 且随浓度不降，线性越好。 |
| **FWHM** | Full Width at Half Maximum，半高全宽，衡量光谱仪分辨相邻吸收峰的能力。 |
| **标准物质/滤光片** | 检验用：钬玻璃/钬氧化物（波长）、中性密度片/重铬酸钾（光度）、NaI/截止滤光片（杂散光）、汞灯/氩灯（分辨率）。 |
| **JJG 178** | 《紫外、可见、近红外分光光度计》检定规程，国内计量溯源依据（波长/光度/杂散光/基线/噪声/分辨率）。 |
| **ASTM E275** | UV-Vis-NIR 分光光度计性能评价标准（波长准确度、光度准确度、杂散光、基线平直度、分辨率、噪声）。 |
