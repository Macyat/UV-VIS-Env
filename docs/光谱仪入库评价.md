# 光谱仪入库评价（SOP）

## 1. 目的与范围

在仪器部署到现场、或复用既有模型之前，按紫外-可见分光光度计的计量检验口径，对仪器硬件做**逐项入库检验**，确认仪器状态合格。本库 `aimeta/hardware_eval.py` 提供从实测光谱**计算指标**的函数；标准物质/滤光片由使用方按检定规程准备。

## 2. 依据标准

- **JJG 178**《紫外、可见、近红外分光光度计》检定规程（国内计量溯源）
- **ASTM E275** 系列（UV-Vis-NIR 分光光度计性能评价）

## 3. 检验项目总览

| 项目 | 标准物质/工具 | 测量操作 | 典型合格判据 | 调用函数 |
|---|---|---|---|---|
| 波长准确度 | 钬玻璃/钬氧化物标准片（特征峰 279.4/287.5/333.7/360.9/418.5/453.2/536.2/637.5 nm）或汞/氩灯 | 测标准片光谱，在每个参考峰 ±window 内抛物线细化取实测峰位，误差 = 实测 − 标称 | ≤ 0.5 nm | `wavelength_accuracy` |
| 光度准确度 | 中性密度片/重铬酸钾标准溶液（已知吸光度点） | 测标准光谱，在认证波长点线性插值取实测值，误差 = 实测 − 认证 | ≤ 0.002 A（或 0.3 %T） | `photometric_accuracy` |
| 杂散光 | NaI/Corning 截止滤光片 | 测透射谱，在滤光片完全截止（≈0%T）波长处插值取残余透射 | ≤ 0.05 %T | `stray_light` |
| 暗噪声 | 无（遮光：shutter 关闭/暗室） | 遮光采集 ≥2 次重复暗谱，逐波长算样本标准差（ddof=1） | ≤ 0.0005（示例） | `dark_noise` |
| 基线平直度 | 空气/空白（100%T 参考） | 多次重复测 100%T 参考线，逐波长跨重复 std；给 ideal 再算最大偏离 | 重复性 ≤ 0.001（示例） | `baseline_flatness` |
| 信噪比 | 稳定光源/纯水 | 同条件重复 ≥10 次，SNR = 信号均值/重复标准差 | 越高越好 | `signal_to_noise` |
| 分辨率 | 汞灯/氩灯等窄发射线 | 测发射线谱，峰 ±window 抛物线细化峰高，线性插值求 FWHM | FWHM ≤ 2 nm | `resolution` |
| 标液线性度（各波长） | 无（多浓度梯度标液） | 测各物质标液多浓度梯度光谱，逐波长按浓度逐步累加线性回归，算累计 R² | 按 R² 曲线定性判断 | `standard_solution_linearity` |

## 4. 数据准备（每项要采集什么）

| 变量 | 形状 | 含义 |
|---|---|---|
| `wl` | (p,) | 波长轴（nm） |
| `dark_repeats` | (n, p) | 遮光重复暗谱 |
| `baseline_repeats` | (n, p) | 100%T 参考线重复 |
| `holmium_spectrum` | (p,) | 钬玻璃实测光谱 |
| `neutral_spectrum` | (p,) | 中性密度片/重铬酸钾实测光谱 |
| `transmittance` | (p,) | 截止滤光片透射谱（%T） |
| `signal_repeats` | (n, p) | 稳定信号重复测量 |
| `line_spectrum` | (p,) | 汞灯/氩灯发射线光谱 |
| `standard_X` | (n, p) | 多浓度梯度标液光谱（线性度，行=浓度梯度） |
| `concentrations` | (n,) | 标液浓度梯度（线性度） |

约定：光谱矩阵**行=重复测量，列=波长**；吸光度用 A，透射比用 %T，波长单位 nm。

## 5. 评价调用

### 5.1 一次性汇总（推荐）

`evaluate_instrument` 所有参数可选，**有数据才算、缺项跳过**（如无汞灯线则不测分辨率）：

```python
from aimeta.hardware_eval import evaluate_instrument

res = evaluate_instrument(
    wavelengths=wl,                    # (p,) 波长轴
    dark_repeats=dark,                 # (n,p) 遮光重复
    baseline_repeats=base,             # (n,p) 100%T 重复
    baseline_ideal=100.0,              # 理想基线值（算 deviation）
    holmium_spectrum=holmium,          # 钬玻璃实测
    ref_peaks=[360.9, 418.5, 536.2],   # 选用峰
    neutral_spectrum=neutral,          # 中性密度片实测
    certified=[(440.0, 0.500), (546.0, 0.300)],  # (波长nm, 认证吸光度)
    transmittance=t_pct,               # %T 透射谱
    check_wl=[340.0],                  # 杂散光检查波长
    signal_repeats=sig,                # (n,p) 稳定信号重复
    signal_at_wl=550.0,                # SNR 计算波长
    line_spectrum=mercury,             # 汞灯线
    line_peak_wl=546.1,                # 汞灯线峰位
)
print(res.report())   # {'metrics': {...}, 'pass_criteria': {...}, 'passed': {...}}
```

### 5.2 单项调用

```python
from aimeta.hardware_eval import (
    wavelength_accuracy, photometric_accuracy, stray_light,
    dark_noise, baseline_flatness, signal_to_noise, resolution,
)

wa   = wavelength_accuracy(wl, holmium, ref_peaks=[360.9, 418.5, 536.2])  # {errors_nm, max_abs_error_nm}
pa   = photometric_accuracy(wl, neutral, certified=[(440.0, 0.5)])        # {errors, max_abs_error}
sl   = stray_light(wl, t_pct, check_wl=[340.0])                            # {stray_light_Tpct, max_Tpct}
dn   = dark_noise(dark)                                                    # {std_max, std_mean}
bf   = baseline_flatness(base, ideal=100.0)                                # {repeatability_max, deviation_max}
snr  = signal_to_noise(sig, at_wl=550.0, wavelengths=wl)                  # float
fwhm = resolution(wl, mercury, peak_wl=546.1)                              # float (nm)
```

### 5.3 标液线性度（各波长）

```python
from aimeta.hardware_eval import standard_solution_linearity
from aimeta.viz.plots import plot_linearity_r2

# standard_X: (n, p) 多浓度梯度标液光谱（行=浓度梯度，升序）；concentrations: (n,)
res = standard_solution_linearity(standard_X, concentrations)
# res["r2"]: (n, p) 累计 R²，r2[k-1, j] = 用前 k 个浓度拟合波长 j 的 R²
# 判定：R² 接近 1 且随浓度不降的连续波长段 → 线性好（Beer-Lambert 成立）

fig = plot_linearity_r2(res["X_smooth"], res["r2"])   # 吸光度 vs R² 散点图
```

## 6. 结果判读与放行

- `evaluate_instrument` 的 `passed` 字段逐项给出是否 ≤ 合格判据（默认 `DEFAULT_LIMITS`，可传 `limits` 覆盖）。
- 波长漂移 > 0.5 nm 必须先重标定，否则 DS/PDS 迁移与 PLS 建模都会错位。
- 杂散光、暗噪声、分辨率不合格，会抬高方法噪声 `s_x`，进而恶化模型 LOD/LOQ。
- 暗噪声/基线/SNR 必须**多次重复**（≥10 组），单次测量无意义。

## 7. 适用说明：光纤/阵列光谱仪

本模块所有函数只依赖「波长数组 + 光谱数组」，不假设扫描机构，对固定光栅的阵列光谱仪同样适用；重心是温度漂移标定、实际积分时间下的 SNR 与杂散光。
